# Agent entry point

1. First ask Robert: what outcome (`prototype` / `new-app` / `existing-app`) and how much time?
2. Read [README.md](README.md), the tree index of skills.
3. Load `core/` plus only the matching `paths/<outcome>/` folder. Do not load the other paths.
4. **Path skills OVERRIDE core skills where they conflict.** Follow the path. Core still applies wherever the path is silent.
5. Open only the `SKILL.md` files whose description matches the current task.
6. Follow links inside a skill only when needed.
7. Skills marked DRAFT are incomplete; ask Robert before relying on them.
8. Load `domains/<name>` only when the problem is in that domain.
