# Design references (Mobbin)
## Rules
- Before designing a screen or flow, search Mobbin for 2-3 real-world references of the same pattern.
- Cite the references (links) in the ticket or agent prompt.
- Copy the pattern, not the brand: adapt to our design system.
- Prefer patterns from well-known products users already understand.
