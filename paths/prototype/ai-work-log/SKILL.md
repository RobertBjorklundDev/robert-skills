# AI work log

- Start at minute one, ideally with a separate silent log-keeper agent.
- Log main steps, not every prompt: what was tried, what was kept, changed or rejected and why.
- Record where AI was wrong and how it was caught, and what Robert deliberately did not let AI do.
- Keep a running "decisions so far" and a time tally against the budget; mark times as estimates.
- Draft a reflection at the end: where AI helped most, where it misled, what to do with more time.

## Lessons seen so far
- AI reasons about the prototype while Robert reasons about the product; check which one an answer is about.
- When AI writes both the code and the expected answers, the human review of the answers is the real check.
- A misconfigured model can make a run look like a result; verify the model was actually called.
- Copy proven patterns from other projects, not their code.
