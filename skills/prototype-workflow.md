# Prototype workflow

A prototype uses the same skills as any other app (`general-new-app`, `general-architecture`, `general-testing`, `backend-workflow`, `ui-workflow`, and the stack skills). This skill does not replace them.

## Rules
- **Test every required behavior.** List each behavior the brief requires. Each item has a test, and the test checks that behavior exactly. Which tests to write, and how, stay with `general-testing` and the stack testing skills.
- **Keep it simple.** Build what the assignment asks for. Do not add layers, features, or flexibility the brief does not need. Simplicity does not skip the other skills.

## Before hand-in
- Every required behavior maps to a test by name.
- The code does only what the brief asks.
